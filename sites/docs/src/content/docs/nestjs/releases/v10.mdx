> Released June 15, 2023. Smaller release than [[nestjs/releases/v11|v11]]: drops Node 12, splits `CacheModule` into `@nestjs/cache-manager`, and ships [[nestjs/recipes/swc-setup|SWC]] in the CLI. Most apps upgrade in an afternoon.

## At a glance

| Change | Type | Impact |
| --- | --- | --- |
| Node.js 16+ required | Breaking | Drop Node 12 from CI |
| `CacheModule` → `@nestjs/cache-manager` | Breaking | Re-import; see [caching recipe](/knowledge-base/nestjs/data/caching/) |
| CLI Plugins need TypeScript 4.8+ | Breaking | Bump `typescript` if Swagger/GraphQL plugins enabled |
| `ES2021` compile target | Behavior | Smaller bundles |
| `nest start -b swc` | Feature | ~20× faster dev builds |
| `Test#overrideModule().useModule()` | Feature | Mock whole modules in e2e tests |
| Redis `wildcards: true` | Feature | Glob `psubscribe` patterns |
| `AsyncLocalStorage` in interceptors | Feature | [trace-id recipe](/knowledge-base/nestjs/recipes/trace-id/) |
| `@Search()` decorator | Feature | `SEARCH` HTTP method handler |
| Middleware once per matched route | Behavior | Stops double-firing on shared paths |

## Breaking changes you'll hit

### Node.js 16+

```json
{ "engines": { "node": ">=16" } }
```

Node 16 is EOL ([Node release schedule](https://github.com/nodejs/Release/blob/main/README.md)). Fresh upgrades in 2024+ should target Node 20+ and read [[nestjs/releases/v11|v11 notes]] (minimum Node 20).

### `CacheModule` moved out of `@nestjs/common`

```bash
npm i @nestjs/cache-manager cache-manager
```

```typescript
// Before (v9)
import { CacheModule, CacheInterceptor } from "@nestjs/common";

// After (v10)
import { CacheModule, CacheInterceptor } from "@nestjs/cache-manager";
```

v11 swaps the store contract to Keyv ([[nestjs/data/caching|caching recipe]], [[nestjs/releases/v11|v11 notes]]).

### CLI Plugins require TypeScript 4.8+

`@nestjs/swagger` and `@nestjs/graphql` plugins need TypeScript 4.8+ ([NestJS 10 announcement](https://trilon.io/blog/nestjs-10-is-now-available)).

```json
{ "devDependencies": { "typescript": "^5.0.0" } }
```

## Features worth knowing

### SWC in the Nest CLI

```bash
npm i --save-dev @swc/core @swc/cli
nest start -b swc --type-check
```

Full setup: [[nestjs/recipes/swc-setup|SWC recipe]], [official SWC recipe](https://docs.nestjs.com/recipes/swc).

### Override whole modules in tests

```typescript
import { Test } from "@nestjs/testing";
import { LoggerModule } from "./logger.module";
import { LoggerTestingModule } from "./logger-testing.module";
import { AppModule } from "./app.module";

const moduleRef = await Test.createTestingModule({
  imports: [AppModule],
})
  .overrideModule(LoggerModule)
  .useModule(LoggerTestingModule)
  .compile();
```

Replacement must export the same public tokens ([e2e testing docs](https://docs.nestjs.com/fundamentals/testing#end-to-end-testing)).

### Redis wildcard subscriptions

```typescript
import { NestFactory } from "@nestjs/core";
import { MicroserviceOptions, Transport } from "@nestjs/microservices";
import { AppModule } from "./app.module";

const app = await NestFactory.createMicroservice<MicroserviceOptions>(AppModule, {
  transport: Transport.REDIS,
  options: { host: "localhost", port: 6379, wildcards: true },
});
await app.listen();
```

### `@Search()` decorator

```typescript
import { Body, Controller, Search } from "@nestjs/common";

@Controller("documents")
export class DocumentsController {
  @Search()
  search(@Body() query: { q: string }) {
    return { hits: [] };
  }
}
```

### Middleware runs once per matched route

v10 deduplicates middleware when multiple handlers share a path ([PR #9809](https://github.com/nestjs/nest/pull/9809)). Audit if you relied on duplicate firing.

## Upgrade checklist

```bash
npx npm-check-updates -u "/^@nestjs\\//" "typescript"
npm install
```

1. Bump Node to 16+ (prefer 20+ for v11 path).
2. Bump `typescript` to >= 4.8 if using Swagger/GraphQL plugins.
3. Replace `CacheModule` imports from `@nestjs/common` with `@nestjs/cache-manager`.
4. Re-run tests (middleware-once behavior).
5. Optional: `nest start -b swc --type-check`.
