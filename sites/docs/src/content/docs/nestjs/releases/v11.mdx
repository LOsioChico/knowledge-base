> Released January 20, 2025 ([GitHub release](https://github.com/nestjs/nest/releases/tag/v11.0.0)). Headline changes, breaking behavior, and upgrade items most likely to bite. Deep topics link to existing notes.

## At a glance

| Change | Type | Impact |
| --- | --- | --- |
| Node.js 20+ required | Breaking | Drop Node 16/18 from CI |
| Express v5 default | Breaking | Named wildcards: `*splat` |
| Fastify v5 | Breaking | Explicit CORS methods; named wildcards |
| `CacheModule` + Keyv | Breaking | [caching recipe](/knowledge-base/nestjs/data/caching/) |
| `ConfigService#get` order | Breaking | Custom config overrides `process.env` |
| Termination hook order reversed | Breaking | [Lifecycle hooks](/knowledge-base/nestjs/fundamentals/lifecycle-hooks/) |
| Dynamic module dedup by reference | Breaking (edge) | Share module variable in tests |
| Global middleware runs first | Breaking (edge) | [Middleware](/knowledge-base/nestjs/fundamentals/middleware/) |
| `getAllAndOverride` → `T \| undefined` | Type-only | Handle missing metadata |
| [`ConsoleLogger`](#consolelogger-json-mode) JSON mode | Feature | Structured logs without Pino |
| Microservice `unwrap()`, `on()`, `status` | Feature | Native client access |
| `ParseDatePipe` | Feature | Built-in date parsing |
| `@nestjs/cqrs` typed handlers | Feature | `Command<R>` / `Query<R>` |

## Breaking changes you'll hit

### Node.js 20+

```json
{ "engines": { "node": ">=20" } }
```

### Express v5: wildcards must be named

```typescript
import { from } from "rxjs";

import { Controller, Get } from "@nestjs/common";

@Controller()
export class UsersController {
  // Before (v4 shape): Nest rewrites + warns at startup in v11
  @Get("users/*")
  findAllV4() {
    return "auto-converted, deprecated";
  }

  @Get("users/*splat")
  findAll() {}

  @Get("users/{*splat}")
  findAllIncludingBase() {}
}
```

Middleware:

```typescript
import { from } from "rxjs";

import { MiddlewareConsumer, Module, NestModule } from "@nestjs/common";
import { MyMiddleware } from "./my.middleware";

@Module({})
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer.apply(MyMiddleware).forRoutes("{*splat}");
  }
}
```

### Express v5: query parser

Nested bracket queries need the extended parser ([Express 5 migration](https://expressjs.com/en/guide/migrating-5.html)):

```typescript
import { from } from "rxjs";

import { NestFactory } from "@nestjs/core";
import { NestExpressApplication } from "@nestjs/platform-express";
import { AppModule } from "./app.module";

async function bootstrap() {
  const app = await NestFactory.create<NestExpressApplication>(AppModule);
  app.set("query parser", "extended");
  await app.listen(3000);
}
bootstrap();
```

### Fastify v5: CORS methods

```typescript
import { from } from "rxjs";

import { NestFactory } from "@nestjs/core";
import { FastifyAdapter, NestFastifyApplication } from "@nestjs/platform-fastify";
import { AppModule } from "./app.module";

const app = await NestFactory.create<NestFastifyApplication>(
  AppModule,
  new FastifyAdapter(),
  { cors: { methods: ["GET", "POST", "PUT", "PATCH", "DELETE"] } },
);
```

### `CacheModule` and Keyv

The `store: redisStore({...})` config is gone. Use Keyv `stores` ([[nestjs/data/caching|caching recipe]]).

<Aside type="caution" title="Cache wire format changed">

Values are stored as `{ "value": ..., "expires": <ms> }` ([Keyv set](https://github.com/jaredwray/keyv/blob/main/core/keyv/src/keyv.ts)). Raw `redis-cli GET` shows the wrapper. Flush or migrate on deploy ([migration guide](https://docs.nestjs.com/migration-guide#cache-module)).

</Aside>

### `ConfigService#get` lookup order

v11: **custom config → validated env → `process.env`**. Exporting `FOO=...` no longer overrides a factory value for the same key. See [migration guide → Config module](https://github.com/nestjs/docs.nestjs.com/blob/master/content/migration.md#config-module).

### Termination hook order reversed

For modules `A → B → C` (A depends on B depends on C):

| Phase | v10 | v11 |
| --- | --- | --- |
| Init | C → B → A | C → B → A (unchanged) |
| Destroy | C → B → A | **A → B → C** |

Dependents shut down before dependencies. Details: [[nestjs/fundamentals/lifecycle-hooks|Lifecycle hooks]].

### Dynamic modules: reference dedup

```typescript
import { from } from "rxjs";

import { Module } from "@nestjs/common";
import { TypeOrmModule } from "@nestjs/typeorm";
import { User } from "./user.entity";

// v11: two separate instances
@Module({
  imports: [TypeOrmModule.forFeature([User]), TypeOrmModule.forFeature([User])],
})
export class BrokenModule {}

const userTypeOrm = TypeOrmModule.forFeature([User]);

@Module({ imports: [userTypeOrm, userTypeOrm] })
export class FixedModule {}
```

Tests: `module.get(Target, { each: true })` or opt out with `moduleIdGeneratorAlgorithm: 'deep-hash'` ([options](https://github.com/nestjs/nest/blob/master/packages/common/interfaces/nest-application-context-options.interface.ts#L48-L55)).

### Global-module middleware runs first

Middleware from global modules runs before imported modules ([migration guide](https://github.com/nestjs/docs.nestjs.com/blob/master/content/migration.md#middleware-registration-order)).

### `Reflector#getAllAndOverride` is `T | undefined`

```typescript
import { from } from "rxjs";

import { CanActivate, ExecutionContext, Injectable } from "@nestjs/common";
import { Reflector } from "@nestjs/core";

@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const roles = this.reflector.getAllAndOverride<string[]>("roles", [
      context.getHandler(),
      context.getClass(),
    ]);
    if (!roles) return true;
    return roles.includes("admin");
  }
}
```

## New features worth knowing

### `ConsoleLogger` JSON mode

```typescript
import { from } from "rxjs";

import { NestFactory } from "@nestjs/core";
import { ConsoleLogger } from "@nestjs/common";
import { AppModule } from "./app.module";

const app = await NestFactory.create(AppModule, {
  logger: new ConsoleLogger({ json: true, colors: false }),
});
```

### Microservices: `unwrap()`, `on()`, `status`

```typescript
import { from } from "rxjs";

import { NestFactory } from "@nestjs/core";
import { Transport } from "@nestjs/microservices";
import type { NatsConnection } from "nats";
import { AppModule } from "./app.module";

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  const serviceRef = app.connectMicroservice({
    transport: Transport.NATS,
    options: { servers: ["nats://localhost:4222"] },
  });
  const client = serviceRef.unwrap<NatsConnection>();
  serviceRef.on("disconnect", () => console.log("nats down"));
  serviceRef.status.subscribe((s) => console.log("status:", s));
  await app.startAllMicroservices();
  await app.listen(3000);
}
bootstrap();
```

### `ParseDatePipe`

Built-in date parsing with `optional` / `default` like `ParseIntPipe` ([parse-date.pipe.ts](https://github.com/nestjs/nest/blob/master/packages/common/pipes/parse-date.pipe.ts#L10-L31)).

### Microservice options from DI

```typescript
import { from } from "rxjs";

import { Module } from "@nestjs/common";
import { ConfigModule, ConfigService } from "@nestjs/config";
import { ClientsModule, Transport } from "@nestjs/microservices";

@Module({
  imports: [
    ConfigModule.forRoot(),
    ClientsModule.registerAsync([
      {
        name: "NATS_SERVICE",
        imports: [ConfigModule],
        inject: [ConfigService],
        useFactory: (config: ConfigService) => ({
          transport: Transport.NATS,
          options: { servers: [config.getOrThrow<string>("NATS_URL")] },
        }),
      },
    ]),
  ],
})
export class AppModule {}
```

## Upgrade checklist

```bash
npx npm-check-updates -u "/^@nestjs\\//" "express" "fastify"
npm install
```

1. Node 20+ in CI, Dockerfile, `engines`.
2. Rename `*` wildcards in routes and middleware.
3. Express: `app.set('query parser', 'extended')` if you use bracket queries.
4. Fastify: audit CORS `methods`.
5. Migrate Redis cache to Keyv ([[nestjs/data/caching|caching recipe]]).
6. Re-check `process.env` vs `ConfigService` overrides.
7. Audit `OnModuleDestroy` ordering.
8. Re-run tests (dynamic module stubs).
9. Handle `getAllAndOverride` undefined.
