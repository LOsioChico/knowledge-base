## Suggested order (new project)

<Steps>

1. [[nestjs/recipes/swc-setup|SWC builder]]: default dev loop for this knowledge base.
2. [[nestjs/recipes/configuration|Configuration with @nestjs/config]]: one place for env loading, validation, and typed settings.

</Steps>
