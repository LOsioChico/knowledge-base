## Planned (not on site yet)

- **Distributed [[effect-ts/observability|tracing]] with OpenTelemetry**: W3C `traceparent` context propagation, log correlation, and dynamic spans.
- **Unified Frontend/Backend Serving**: Serve React/Next.js and NestJS on a single port via reverse proxying or [[nestjs/recipes/monorepo|monorepo]] deployment configurations.
- **Background jobs with BullMQ**: Redis-backed robust task queues, job retries, backoff strategies, and [[effect-ts/concurrency|concurrency]] control.
- **Transactional email integration**: Automated email flows using React Email and Resend API.
- **WebSockets Gateway**: Bi-directional real-time communication with Socket.io/`ws`, connection guard authentication, and namespace isolation.
- **S3 / Cloud Storage Streaming**: Direct-to-bucket multi-part [[nestjs/recipes/file-uploads|file uploads]] and presigned URL access patterns.
