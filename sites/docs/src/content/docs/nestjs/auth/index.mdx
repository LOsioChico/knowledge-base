## Planned

- **Guards vs. [[nestjs/fundamentals/middleware|Middleware]] Architecture**: Structural comparison detailing when to intercept requests at the HTTP adapter level vs. inside NestJS exception-handling zone (see [[nestjs/fundamentals/middleware|middleware]] and [[nestjs/fundamentals/guards|guards]]).
- **Fine-Grained Access Control (RBAC & ABAC)**: Designing declarative role checks and dynamic claims-based or attribute-based authorization engines.
- **Refresh Tokens & Rotation Security**: Implementing secure token refresh mechanics, dynamic token rotation patterns, and Redis-backed invalidation blacklists.
- **Session-Based Authentication**: Integrating stateful sessions (`express-session` / Passport session) for applications requiring instantaneous server-side revocation.
- **Third-Party Federated Identity (OAuth2)**: Multi-provider social logins (Google, GitHub, Apple) using unified Passport strategy routing.
