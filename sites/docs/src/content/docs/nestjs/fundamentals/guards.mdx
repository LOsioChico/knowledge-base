## Contract

```typescript
import { Observable } from "rxjs";

import { CanActivate, ExecutionContext, Injectable } from "@nestjs/common";
import { Request } from "express";

@Injectable()
export class AuthGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean | Promise<boolean> | Observable<boolean> {
    const request = context.switchToHttp().getRequest<Request>();
    return Boolean(request.headers.authorization);
  }
}
```

| Return | Effect |
| --- | --- |
| `true` | [Continue to interceptors → pipes → handler](#1-authorized-request-user-has-admin-role) |
| `false` | [Nest throws `ForbiddenException` (`403`)](#2-unauthorized-request-role-mismatch) |
| Thrown error | [Exception filters](/knowledge-base/nestjs/fundamentals/exception-filters/) handle it |

`canActivate` returns `false` on a protected route:

```json
{
  "statusCode": 403,
  "message": "Forbidden resource",
  "error": "Forbidden"
}
```

(Exact `message` depends on your exception filter or `ForbiddenException` constructor.)

<Aside type="caution" title="Pass the class, not an instance">

`@UseGuards(RolesGuard)`: DI wires `Reflector`, repos, config. `@UseGuards(new RolesGuard())` skips DI; `this.reflector` is `undefined`. Same rule for interceptors, pipes, and filters.

</Aside>

## Why not middleware?

[[nestjs/fundamentals/middleware|Middleware]] runs on raw HTTP with **no** `ExecutionContext`. Guards read **handler metadata** (`@Roles()`, `@Public()`) via `getHandler()` / `getClass()`. That is what makes route-level authorization declarative ([Guards](https://docs.nestjs.com/guards)).

## ExecutionContext (what guards actually use)

| Method | Returns |
| --- | --- |
| `getHandler()` | Handler function about to run (worked example: [RolesGuard](#roles-guard-canonical-recipe)) |
| `getClass()` | Controller class (`CatsController`) (worked example: [RolesGuard](#roles-guard-canonical-recipe)) |
| `switchToHttp()` | `getRequest()`, `getResponse()`, `getNext()` (worked example: [RolesGuard](#roles-guard-canonical-recipe)) |
| `getType()` | `'http' \| 'rpc' \| 'ws'` |

`Reflector` reads metadata from `getHandler()` and `getClass()`. Source: [Execution context](https://docs.nestjs.com/fundamentals/execution-context).

## Roles guard (canonical recipe)

<Steps>

1. **Declare metadata** with `Reflector.createDecorator<string[]>()`.
2. **Attach** `@Roles(['admin'])` on handlers that need it.
3. **Implement** `RolesGuard` with `getAllAndOverride` (route overrides class).
4. **Register** `@UseGuards(RolesGuard)` on controller or `APP_GUARD`.

</Steps>

```typescript title="roles.decorator.ts"
import { Reflector } from "@nestjs/core";

export const Roles = Reflector.createDecorator<string[]>();
```

```typescript title="roles.guard.ts"
import { CanActivate, ExecutionContext, Injectable } from "@nestjs/common";
import { Reflector } from "@nestjs/core";
import { Request } from "express";
import { Roles } from "./roles.decorator";

@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(ctx: ExecutionContext): boolean {
    const required = this.reflector.getAllAndOverride(Roles, [
      ctx.getHandler(),
      ctx.getClass(),
    ]);
    if (!required?.length) return true; // no @Roles() → allow

    const request = ctx.switchToHttp().getRequest<Request & { user?: { roles: string[] } }>();
    return Boolean(request.user?.roles?.some((r) => required.includes(r)));
  }
}
```

### Controller binding

```typescript title="cats.controller.ts"
import { Controller, Get, UseGuards, Param } from "@nestjs/common";
import { RolesGuard } from "./roles.guard";
import { Roles } from "./roles.decorator";

@Controller("cats")
@UseGuards(RolesGuard)
export class CatsController {
  @Get(":id")
  @Roles(["admin"])
  findOne(@Param("id") id: string) {
    return { id: Number(id) };
  }
}
```

### Show the behavior

When a route is protected with `@Roles(['admin'])`, the incoming request headers and internal user state determine whether Nest allows execution or throws a `403`:

#### 1. Authorized Request (user has 'admin' role)
* **HTTP exchange**:
  ```json
  GET /cats/1
  Headers: Authorization: Bearer <valid-admin-token>
  (Request user is decoded as: { "username": "alice", "roles": ["admin"] })

  → 200 OK
  {
    "id": 1
  }
  ```

#### 2. Unauthorized Request (role mismatch)
* **HTTP exchange**:
  ```json
  GET /cats/1
  Headers: Authorization: Bearer <valid-user-token>
  (Request user is decoded as: { "username": "bob", "roles": ["user"] })

  → 403 Forbidden
  {
    "statusCode": 403,
    "message": "Forbidden resource",
    "error": "Forbidden"
  }
  ```

| `Reflector` API | Use when |
| --- | --- |
| `getAllAndOverride(d, [handler, class])` | Route metadata **wins** over controller (roles, `@Public()`); [roles guard](#roles-guard-canonical-recipe) |
| `getAllAndMerge(d, [..])` | Combine arrays from class + route |

## Common errors

| Symptom | Likely cause |
| --- | --- |
| `403` unexpectedly | Guard returned `false`: check order; earlier guard may have failed (see worked [unauthorized example](#2-unauthorized-request-role-mismatch)) |
| `this.reflector` undefined | Passed `new RolesGuard()` instead of `RolesGuard` (which bypasses DI; see correct [Reflector DI injection](#roles-guard-canonical-recipe)) |
| `@Roles()` ignored | Wrong reflector method: use `getAllAndOverride` for override semantics ([worked example](#roles-guard-canonical-recipe)) |
| Public route blocked | Global guard runs first: add `@Public()` + `Reflector` skip ([Passport recipe](https://docs.nestjs.com/recipes/passport)) |
