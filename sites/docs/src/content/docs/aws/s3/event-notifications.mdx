> S3 event notifications fire to [[aws/sns|SNS]], [[aws/sqs|SQS]], [[aws/lambda|Lambda]], or [[aws/eventbridge|EventBridge]] when configured object lifecycle events occur: turning a passive bucket into an event-driven pipeline front.

## Event families

Ten activity types including Intelligent-Tiering auto-tier ([source](https://docs.aws.amazon.com/AmazonS3/latest/userguide/notification-how-to-event-types-and-destinations.html#supported-notification-event-types)):

| Family | Wildcard | Notes |
| --- | --- | --- |
| Object created | `s3:ObjectCreated:*` | Put, Post, Copy, CompleteMultipartUpload; [example](#minimum-config-sqs-prefix-filter) |
| Object removed | `s3:ObjectRemoved:*` | **Not fired for lifecycle deletes**: use `LifecycleExpiration:*` |
| Object restored | `s3:ObjectRestore:*` | Glacier restore lifecycle |
| Lifecycle expiration | `s3:LifecycleExpiration:*` | Lifecycle-driven deletes |
| Replication | `s3:Replication:*` | Failures, thresholds |

## Destinations

One destination per configuration; must be **same Region** as bucket. Destination needs policy allowing `s3.amazonaws.com`.

## Minimum config (SQS, prefix filter)

```json
{
  "QueueConfigurations": [
    {
      "Id": "uploads-to-process",
      "QueueArn": "arn:aws:sqs:us-east-1:123456789012:uploads-queue",
      "Events": ["s3:ObjectCreated:*"],
      "Filter": {
        "Key": {
          "FilterRules": [
            { "Name": "prefix", "Value": "incoming/" },
            { "Name": "suffix", "Value": ".jpg" }
          ]
        }
      }
    }
  ]
}
```

```bash
aws s3api put-bucket-notification-configuration \
  --bucket my-bucket \
  --notification-configuration file://notification.json
```

S3 sends a one-time `s3:TestEvent` on configure: if missing, fix destination policy.

## Delivery semantics

- **At-least-once**: handler must be idempotent.
- **Not ordered**: use `versionId` / `LastModified`, not delivery order.
- **Seconds typical**, sometimes minutes ([source](https://docs.aws.amazon.com/AmazonS3/latest/userguide/EventNotifications.html#EventNotifications)).

<Aside type="caution" title="Recursion footgun">
Lambda writes back to the same bucket without prefix filter → infinite loop billed by the second. Safe patterns: separate buckets or disjoint prefixes (`in/` trigger, `out/` writes).
</Aside>

<Aside type="caution" title="Overlapping filters rejected">

Two rules cannot match the same object: use disjoint prefixes or fan out via SNS/EventBridge.

</Aside>

## When EventBridge instead

Reach for [[aws/eventbridge|EventBridge]] instead of direct S3 notifications when you need:

- Content-based filtering beyond prefix/suffix.
- Multiple downstream consumers without SNS fan-out.
- SQS FIFO downstream (via EventBridge only).
- Uniform envelope across services.
