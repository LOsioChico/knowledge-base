> Read + snapshot + restore for [[aws/rds|RDS]]. The snapshot family is the entire migration surface; the rest is inventory.

<Aside type="tip" title="Prerequisites">
Before diving in, make sure you understand:
- [[aws/cli/profiles-and-credentials|AWS Profiles & Credentials]]: since managing database clusters and instances requires profile-based CLI requests.
</Aside>

## Inventory + state

```bash
aws rds describe-db-instances        --db-instance-identifier <id>
aws rds describe-db-snapshots        --db-snapshot-identifier <id>
aws rds describe-db-snapshot-attributes --db-snapshot-identifier <id>

aws rds describe-db-instances \
  --query 'DBInstances[].{Id:DBInstanceIdentifier,Status:DBInstanceStatus,Engine:Engine,Class:DBInstanceClass,MultiAZ:MultiAZ}' \
  --output table
```

## Snapshot lifecycle

```bash
aws rds create-db-snapshot \
  --db-instance-identifier <id> \
  --db-snapshot-identifier <name>

aws rds copy-db-snapshot \
  --source-db-snapshot-identifier <src> \
  --target-db-snapshot-identifier <dst> \
  [--kms-key-id <key>] [--source-region <region>]

aws rds modify-db-snapshot-attribute \
  --db-snapshot-identifier <name> \
  --attribute-name restore \
  --values-to-add <ACCOUNT_ID>

aws rds delete-db-snapshot --db-snapshot-identifier <name>
```

## Restore

```bash
aws rds restore-db-instance-from-db-snapshot \
  --db-instance-identifier <new-id> \
  --db-snapshot-identifier <snap> \
  [--db-instance-class db.t4g.medium] \
  [--db-subnet-group-name <subnet-group>] \
  [--vpc-security-group-ids sg-xxxx]
```

## Wait for state transitions

```bash
aws rds wait db-snapshot-available  --db-snapshot-identifier <name>
aws rds wait db-instance-available  --db-instance-identifier <id>
aws rds wait db-instance-deleted    --db-instance-identifier <id>
```

## Tips

- Always `wait` between create/copy/restore in scripts: else `InvalidDBSnapshotState`.
- Full cross-account + [[aws/kms|KMS]] sequence: [[aws/rds/cross-account-snapshot|cross-account RDS snapshot]].
- See [[aws/cli/profiles-and-credentials|profiles and credentials]] for multi-account `--profile`.
