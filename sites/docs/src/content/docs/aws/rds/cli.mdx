## Inventory + state

### Describe specific database instance
Retrieve detailed metadata about a single database instance to check its endpoint, size, engine, and status:
```bash
aws rds describe-db-instances --profile $AWS_PROFILE --region $REGION \
  --db-instance-identifier $DB_INSTANCE_ID
```

### Describe specific snapshot
Retrieve metadata for a specific database snapshot, including its engine type, allocation, and lifecycle state:
```bash
aws rds describe-db-snapshots --profile $AWS_PROFILE --region $REGION \
  --db-snapshot-identifier $SNAPSHOT_ID
```

### Inspect snapshot access attributes
Inspect who has permission to restore a database snapshot (e.g. public vs. shared with specific account IDs):
```bash
aws rds describe-db-snapshot-attributes --profile $AWS_PROFILE --region $REGION \
  --db-snapshot-identifier $SNAPSHOT_ID
```

### List all instances in a table
Summarize all active database instances, their configurations, engine types, and statuses in a clean table format:
```bash
aws rds describe-db-instances --profile $AWS_PROFILE --region $REGION \
  --query 'DBInstances[].{Id:DBInstanceIdentifier,Status:DBInstanceStatus,Engine:Engine,Class:DBInstanceClass,MultiAZ:MultiAZ}' \
  --output table
```

## Snapshot lifecycle

### Create a manual snapshot
Trigger an instant, manual cold backup of a target database instance:
```bash
aws rds create-db-snapshot --profile $AWS_PROFILE --region $REGION \
  --db-instance-identifier $DB_INSTANCE_ID \
  --db-snapshot-identifier $SNAPSHOT_ID
```

### Copy a snapshot (optionally encrypting it)
Copy a snapshot to a new ID, enabling you to re-encrypt it using a custom KMS key or copy it across regions:
```bash
aws rds copy-db-snapshot --profile $AWS_PROFILE --region $REGION \
  --source-db-snapshot-identifier $SNAPSHOT_ID \
  --target-db-snapshot-identifier $SNAPSHOT_ID-copy \
  [--kms-key-id $KMS_KEY_ID] [--source-region $REGION]
```

### Share snapshot with target account
Modify snapshot attributes to grant restore permissions to a different, target AWS account:
```bash
aws rds modify-db-snapshot-attribute --profile $AWS_PROFILE --region $REGION \
  --db-snapshot-identifier $SNAPSHOT_ID \
  --attribute-name restore \
  --values-to-add $TARGET_ACCOUNT_ID
```

### Delete a snapshot
Permanently delete a database snapshot to clean up backup storage:
```bash
aws rds delete-db-snapshot --profile $AWS_PROFILE --region $REGION \
  --db-snapshot-identifier $SNAPSHOT_ID
```

## Restore

### Restore instance from snapshot
Create a new database instance directly from an existing backup snapshot:
```bash
aws rds restore-db-instance-from-db-snapshot --profile $AWS_PROFILE --region $REGION \
  --db-instance-identifier $DB_INSTANCE_ID-restored \
  --db-snapshot-identifier $SNAPSHOT_ID \
  [--db-instance-class db.t4g.medium] \
  [--db-subnet-group-name default] \
  [--vpc-security-group-ids sg-default]
```

## Wait for state transitions

### Wait for snapshot readiness
Pause script execution until a newly created or copied database snapshot becomes fully available:
```bash
aws rds wait db-snapshot-available --profile $AWS_PROFILE --region $REGION \
  --db-snapshot-identifier $SNAPSHOT_ID
```

### Wait for instance readiness
Pause script execution until a newly launched or restored database instance completes provisioning:
```bash
aws rds wait db-instance-available --profile $AWS_PROFILE --region $REGION \
  --db-instance-identifier $DB_INSTANCE_ID
```

### Wait for instance deletion
Pause execution until a deleted database instance is completely torn down:
```bash
aws rds wait db-instance-deleted --profile $AWS_PROFILE --region $REGION \
  --db-instance-identifier $DB_INSTANCE_ID
```

## Tips

- Always `wait` between create/copy/restore in scripts: else `InvalidDBSnapshotState`.
- Full cross-account + [[aws/kms|KMS]] sequence: [[aws/rds/cross-account-snapshot|cross-account RDS snapshot]].
