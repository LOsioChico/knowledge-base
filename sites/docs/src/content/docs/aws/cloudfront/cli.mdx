## Find a distribution

### List all distributions in a table
Summarize IDs, domain names, hostnames, and statuses for all CloudFront distributions in a clean table format:
```bash
aws cloudfront list-distributions --profile $AWS_PROFILE \
  --query 'DistributionList.Items[].{Id:Id,Domain:DomainName,Aliases:Aliases.Items,Status:Status}' \
  --output table
```

### Find distribution by hostname
Find the exact distribution ID and DNS domain name that serves a specific alternate domain name (CNAME):
```bash
aws cloudfront list-distributions --profile $AWS_PROFILE \
  --query "DistributionList.Items[?Aliases.Items != null && contains(Aliases.Items, '$HOSTNAME')].{Id:Id,Domain:DomainName}" \
  --output table
```

### Get distribution details
Retrieve full details and status of a specific CloudFront distribution:
```bash
aws cloudfront get-distribution --profile $AWS_PROFILE \
  --id $DISTRIBUTION_ID
```

### Get distribution configuration
Retrieve only the configuration properties (origins, behaviors, caching rules) without the full read status payload:
```bash
aws cloudfront get-distribution-config --profile $AWS_PROFILE \
  --id $DISTRIBUTION_ID
```

## Invalidate the CDN

### Invalidate all paths
Flush the entire CDN cache instantly by invalidating the root wildcard path:
```bash
aws cloudfront create-invalidation --profile $AWS_PROFILE \
  --distribution-id $DISTRIBUTION_ID \
  --paths '/*'
```

### Invalidate specific files
Flush specific static asset files and file paths from the cache:
```bash
aws cloudfront create-invalidation --profile $AWS_PROFILE \
  --distribution-id $DISTRIBUTION_ID \
  --paths '/index.html' '/static/css/*'
```

### List recent invalidations
List the status and ID of recent invalidation jobs to track progress:
```bash
aws cloudfront list-invalidations --profile $AWS_PROFILE \
  --distribution-id $DISTRIBUTION_ID
```

### Inspect specific invalidation progress
Check the status (`InProgress` vs `Completed`) of a specific invalidation job ID:
```bash
aws cloudfront get-invalidation --profile $AWS_PROFILE \
  --distribution-id $DISTRIBUTION_ID \
  --id $INVALIDATION_ID
```

First 1,000 paths/month free; wildcards count as one path.

## Update a distribution

Read-modify-write with optimistic concurrency:

### Download configuration and tag ETag
Download the current configuration payload and save it:
```bash
aws cloudfront get-distribution-config --profile $AWS_PROFILE \
  --id $DISTRIBUTION_ID > dist.json
```

### Extract ETag header
Extract the unique ETag version token to send with your update call to prevent concurrent overwrite clashes:
```bash
ETAG=$(jq -r .ETag dist.json)
```

### Extract editable configuration chunk
Filter only the editable config sub-object into a separate clean JSON file:
```bash
jq .DistributionConfig dist.json > dist-config.json
```

### Apply updated configuration
Submit the modified configuration JSON file back to CloudFront along with the correct ETag version token:
```bash
# Edit dist-config.json (e.g. modify origins or CNAMEs)
aws cloudfront update-distribution \
  --profile $AWS_PROFILE \
  --id $DISTRIBUTION_ID \
  --distribution-config file://dist-config.json \
  --if-match "$ETAG"
```

<Aside type="caution" title="Stale ETag rejects updates">
Stale `--if-match` rejects the update: refetch and retry.
</Aside>
