## Before you start

- AWS CLI profile that resolves to a writable account: [[aws/cli/profiles-and-credentials|profiles and credentials]]. Verify `Account` in the JSON matches the account you intend to bill:

  ```bash
  aws --profile <name> sts get-caller-identity
  ```

Shared variables for every command below:

```bash
export AWS_PROFILE=<your-profile>
export REGION=us-east-1
export ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
export TABLE_NAME=quickstart-dynamo-${ACCOUNT_ID}
```

The table name includes your account ID to prevent global naming conflicts.

## 1. Create the table

We configure the table with a partition key `PK` and sort key `SK` using pay-per-request (on-demand capacity billing) to ensure fast initialization and zero idle fees:

```bash
aws dynamodb create-table \
  --table-name "$TABLE_NAME" \
  --attribute-definitions \
    AttributeName=PK,AttributeType=S \
    AttributeName=SK,AttributeType=S \
  --key-schema \
    AttributeName=PK,KeyType=HASH \
    AttributeName=SK,KeyType=RANGE \
  --billing-mode PAY_PER_REQUEST \
  --region "$REGION"

# Block execution until the table is active and ready
aws dynamodb wait table-exists --table-name "$TABLE_NAME" --region "$REGION"
```

## 2. Put an item

Write a structured JSON item defining a user profile to the table. In DynamoDB, attributes other than the keys are dynamic:

```bash
aws dynamodb put-item \
  --table-name "$TABLE_NAME" \
  --item '{
    "PK": {"S": "USER#100"},
    "SK": {"S": "PROFILE"},
    "Email": {"S": "alice@example.com"},
    "Status": {"S": "ACTIVE"}
  }' \
  --region "$REGION"
```

## 3. Get and query the item

Confirm the record exists. Fetch a single item directly using its exact key combination, filtering the output with JMESPath:

```bash
aws dynamodb get-item \
  --table-name "$TABLE_NAME" \
  --key '{"PK": {"S": "USER#100"}, "SK": {"S": "PROFILE"}}' \
  --query "Item.{Email: Email.S, Status: Status.S}" \
  --output json \
  --region "$REGION"
# Output:
# {
#   "Email": "alice@example.com",
#   "Status": "ACTIVE"
# }
```

You can also run a `query` to search using a key condition expression and custom attribute values:

```bash
aws dynamodb query \
  --table-name "$TABLE_NAME" \
  --key-condition-expression "PK = :pk AND begins_with(SK, :sk)" \
  --expression-attribute-values '{
    ":pk": {"S": "USER#100"},
    ":sk": {"S": "PROF"}
  }' \
  --query "Items[].{Email: Email.S}" \
  --output json \
  --region "$REGION"
# Output:
# [
#   {
#     "Email": "alice@example.com"
#   }
# ]
```

## 4. Clean up

To avoid leaving orphaned resources, delete the table:

```bash
aws dynamodb delete-table --table-name "$TABLE_NAME" --region "$REGION"
```
